Mis Proyectos

API de películas

API REST para gestionar un catálogo de películas (título, año, duración, género y director). Expone un CRUD completo en /movies/ con un ViewSet y un router de Django REST Framework, y está desplegada en Render con mi propio dominio, así que puedes probarla desde el navegador.

Tecnologías: Python, Django, Django REST Framework, SQLite, Render

Amatist TCG

Tienda online de cartas coleccionables hecha en equipo de tres para la universidad. Los clientes se registran, guardan favoritos y compran desde el catálogo; cada pedido pasa por estados (preparando, enviado, entregado, cancelado) y el cliente recibe un correo en cada cambio. El panel de administración, protegido por roles, permite gestionar productos, pedidos y ver estadísticas de favoritos. Disponible en español e inglés.

Tecnologías: PHP 8, Laravel 9, MySQL, Laravel Fortify, Bootstrap 5
