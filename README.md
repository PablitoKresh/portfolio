## 🚀 Sobre mí
Estudiante de último curso de Ingeniería Informática (mención en Sistemas de Información), centrado en el backend, las bases de datos y el análisis de datos.
Trabajo principalmente con **Python**, **Django REST Framework**, **Laravel** y bases de datos **SQL**.

## 🖥️ Tecnologías del portfolio
- **HTML5**
- **TailwindCSS (CDN)** con una paleta propia en CSS
- **Render** (hosting) con dominio personalizado `.dev`

No usa frameworks ni herramientas de compilación: es una sola página, rápida y fácil de mantener.
